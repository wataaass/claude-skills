# save-progress

目的: 会話をクリアしたあとの Claude が、PROGRESS.md だけを読んで続きから再開できるようにする。

`PROGRESS.md` を読み、見出しの構成は変えずに、各見出しを今の状態に書き直す。
- 最終更新: 今日の日付（YYYY-MM-DD）
- 今やっていること: 進行中の作業とどの段階か。なければ「なし」
- 次にやること: 次の一手を先頭に、そのあと候補。終わったものは消す
- 未決定・確認待ち: 返事待ちの質問や未決のこと。なければ「なし」
- 最近の完了: 新しいものを先頭に足し、5件を超えた分は削る。コミットがあればハッシュも書く

書き方: 日付は「今日」でなく絶対日付で書く。毎回読み込まれるので全体で60行以内にする。詳しい経緯は Git や README に任せる。パスワードや個人情報は書かない。

最後に、何を更新したかを1〜2文で報告する。
