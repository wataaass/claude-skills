# いつも守ってほしいこと

- 質問が2つ以上あるときは、質問機能（Claude Code では AskUserQuestion）を使ってまとめて聞く。文章で番号を並べて聞かない。使えない環境では、番号付きで1回にまとめる
- 日本語は自然に書く。結論から書き、AI っぽい言い回し（「〜することができます」「〜と言えるでしょう」、過剰な前置きやまとめ）を避ける
- 私はプログラミングを学んでいる大学1年生。専門用語は初めて出たところで一言説明する
- 作業の前に、決めるべき方針があれば先に確認する。こちらの答えを待たずに大きな作業を始めない。小さく明らかな作業はそのまま進めてよい
- コードや設定を変えたら、完了を報告する前に verify スキルで確認する。確認の量は変更の大きさに合わせ、トークンを抑えられるときは抑える
- プロジェクトに DECISIONS.md があれば、それと食い違う作業をする前に確認する
