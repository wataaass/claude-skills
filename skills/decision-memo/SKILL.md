# decision-memo

**書き出す**: プロジェクト直下の `DECISIONS.md` に追記する（なければ作る）。プロジェクトがない会話では同じ形式で会話に出し、保存先を聞く。1項目5行以内で、理由のない決定は書かない。
```markdown
## <見出し>（YYYY-MM-DD）
- 決定: <する／しないこと>
- 理由: <なぜ>
- 却下した案: <案と理由>（あれば）
```
決定を覆したら、古い項目は消さずに「→ YYYY-MM-DD に変更（<新しい見出し>）」と追記する。`CLAUDE.md` があって `@DECISIONS.md` がまだなければ、一言断ってから1行足す（毎回自動で読み込まれるようになる）。

**照らし合わせる**: 作業前に見出しだけ読み、関係する項目の本文を読む。頼まれた作業や自分の案が決定と食い違うなら手を止め、どの決定とどう食い違うかを1〜2文で示す。そのうえで「決定を変える／今回だけ例外／作業のほうを直す」を質問機能で聞く。黙って進めることも、黙って頼まれた内容を変えることもしない。
