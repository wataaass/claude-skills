# job-hunting-docs

面接で深掘りされるので、本人の実際の経験と言葉だけで書く。作り話や誇張は入れない。

**1. 前提**（質問機能でまとめて聞く）: 文書の種類と設問文（そのまま貼ってもらう）、文字数の上限、応募先と職種（志望動機なら選んだ理由のメモも）。

**2. 経験の聞き出し**: 質問機能で1回2〜4問ずつ、状況 → 課題 → 自分の行動（AI や他人の分と分ける）→ 結果（数字があれば数字）→ 学びと次への生かし方、の順に掘る。ポートフォリオサイト、study-log、README や DECISIONS.md は、読んでよいか聞いてから候補探しに使う。本人が確認していない内容は使わない。

**3. 下書き**: 伝えたいことを1文目に置き、上限の90〜100%に収め、natural-japanese で推敲する。あわせて面接で聞かれそうな深掘りの質問を3つ出す。答えに詰まりそうな部分は外すか、経験を聞き直す。

**添削だけのとき**: 本人の文章を土台にし、全面的には書き換えない。直した箇所と理由を示す。
