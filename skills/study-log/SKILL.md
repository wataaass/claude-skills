# study-log

記録は就活の自己PRや、ポートフォリオの学習タイムラインの材料になる。

**保存先**: `wataaass/study-log` の `logs/YYYY/YYYY-MM-DD.md`。同じ日なら追記する。届け方は次の順で試す。
1. 手元に clone があれば書いてコミットしてプッシュする（場所が不明ならホーム以下で `study-log` を探す）
2. クラウドで GitHub のツールが使えれば、study-log をセッションに追加して書く
3. どちらも無理なら、貼れる形の本文と保存先のパスを出す

**形式**:
```markdown
## <テーマ>（<所要時間。不明なら省く>）
- 学んだこと: <本人の言葉で1〜3行>
- つまずいた点: <あれば>
- 次にやること: <あれば>
- 節目: <あれば。「初めて〜できた」「〜を公開した」など>
```

**進め方**: 会話から下書きを作り、分からない項目だけを質問機能でまとめて聞く。「学んだこと」は Claude の説明をコピーせず、「一言で言うと？」と聞いた答えなど本人の言葉を使う。書いたらパスと内容を短く見せる。

**振り返り**: 期間内のファイルを読み、テーマごとにまとめる。「節目」はタイムラインの候補として一覧で出す。
