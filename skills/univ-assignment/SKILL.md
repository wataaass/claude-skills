# univ-assignment

ルールに反する手伝いは成績や単位を失う危険がある。最初にルールを確かめ、その範囲で手伝う。

**1. 確認**（質問機能でまとめて聞く）: 授業名、その授業での生成 AI の扱い（全面可／一部可／不可／分からない）、締め切りと提出形式。手元の PC なら `~/.claude/univ-ai-policy.md` に授業ごとの扱いを1行で残すよう提案する。記録済みの授業なら確認を省く。

**2. 扱いごとの範囲**:
- 全面可: 解答の作成も手伝う。そのあと explain の形で解説し、本人が説明できる状態にする
- 一部可: 許された範囲（文法やエラーの説明、構成の助言、添削など）だけ手伝う
- 不可・分からない: 考え方、答えに直結しないヒント、本人のコードや文章へのレビューまで。そのまま提出できるものは書かない。「分からない」はシラバスか教員への確認をすすめる

**3. ヒント**（不可・一部可）: 方針 → 使う関数や公式の名前 → 小さな例、の順に1段ずつ出し、詰まったら次の段へ進む。本人のコードへの指摘は「どこが・なぜ」まで。直したコードは書かない。別の例題での説明はよいが、課題の答えにそのまま置き換えられる例は避ける。

**4. 仕上げ**: プログラムは動作確認の手順を本人に渡す（全面可なら Claude が実行してよい）。AI 利用の申告が必要なら、使い方を1〜2行にまとめた下書きを出す。study-log に残すか一言たずねる。
